添加本地视频、图片或音频，用对话生成剪辑方案、封面、口播和成片。上传视频后，FFmpeg 自动找出切镜点并显示镜头缩略图；可用对话挑选镜头、拼接片段并加入上传的音乐或内置轻快配乐。口播可以单独试听与下载，也可以通过对话加入 MP4。所有生成任务以后台任务执行，刷新页面后仍可查看结果或重试。

## 启动

需要 Node.js 24 和 pnpm。首次运行：

```bash
pnpm install
pnpm dev
```

打开 <http://127.0.0.1:5173/>，管理后台在 <http://127.0.0.1:5173/admin>。开发时 H5 使用 Vite 的 5173 端口，API 使用 8787 端口。正式本机运行可先执行 `pnpm build`，再执行 `pnpm start`，通过 <http://127.0.0.1:8787/> 访问。

首页为 Landing，注册时填写显示名称、邮箱、邮件中的 6 位验证码与至少 10 位密码；登录后进入当前帐号的对话工作区。用户中心可修改密码或退出登录。帐号密码哈希、验证码哈希和登录会话保存在 `data/auth.json`，会话、素材与成片按帐号隔离；该文件和模型配置一样不提交到 Git。当前未接入自助密码找回。

这台开发机的本地和线上测试帐号记录在 `data/TEST_ACCOUNTS.local.md`。该文件含密码，位于 Git 忽略的 `data/` 目录，仅供本机验收使用；在其他机器上需单独准备测试帐号。

首次启动时，服务端在 `data/admin-token` 生成管理员令牌。仅在本机读取该文件，将令牌填入管理后台。管理后台可维护文本、图片、口播生成和音频理解模型的厂商、模型 ID、服务地址、启用状态及 API Key，并设置新对话默认文本模型。API Key 使用本机令牌派生的密钥加密保存在 `data/provider-models.json`，普通页面和管理后台读取接口都不会回传完整密钥。`data/` 不提交到 Git。请妥善备份 `admin-token` 与模型配置文件，两者需要配套恢复。

默认预置的模型条目需要在后台填入你自己的 API Key 才能使用：

| 用途 | 预置模型 |
| --- | --- |
| 对话与剪辑规划（默认） | `doubao-seed-2-1-pro-260915` |
| 对话与剪辑规划（可切换） | `deepseek-v4-pro-ga-260813` |
| 对话与剪辑规划（可切换） | `glm-5-3-flash-260828` |
| 图片生成 | `doubao-seedream-5-0-flash-260915` |
| 口播音频 | `seed-audio-1.0` |
| 音频理解 / ASR | `doubao-seed-2-1-lite-260915` |

用户可在设置页的“对话模型”中切换，保留当前对话与素材，从下一条消息起生效，并用于之后创建的新会话；任务排队或执行时需等完成后再切换。对话页专注于内容，不显示模型选择或消息模型标记。管理后台的评测页能选择这三个文本模型运行同一组用例，实际模型信息保留在任务记录中。

首次升级会补齐缺少的预置条目，保留已有配置和默认选择。新预置的 DeepSeek 与 GLM 默认引用同一方舟文本模型的服务端密钥，密钥更新后自动跟随；也可以在后台分别配置独立密钥。引用来源的厂商或服务地址改变后不再共用密钥。GLM 5.3 Flash 保持开启思考，思考内容仅用于服务端 Agent 工具循环，普通对话只展示回复工具中的用户可见内容。

## 使用流程

1. 在对话页添加视频、图片或 MP3/WAV/OGG 音频。素材库中可预览视频自动识别的分镜及缩略图，点击镜头会填写剪辑指令。
2. 发送剪辑指令，Pi Agent 读取切镜时间点，通过受校验的工具生成片段方案。继续发送消息调整时长、比例、顺序或片段。切镜检测不等于画面语义理解。
3. 通过对话要求生成口播或图片。口播卡片显示文案和独立音频；图片卡片可预览、下载，结果同时进入素材库。选择一张图片后发送“把这张图片设为封面”，或明确要求把图片加入视频片段。
4. 发送“搜索轻快 BGM”会由 Pi Agent 整理关键词，并显示 Pixabay、24bit 的原站入口。集成方可调用 `/api/music/search` 等服务端接口，或在用户已打开的原站页面运行 `scripts/music-browser-client.js`，让 Chrome 在同源请求中使用现有会话状态。服务端直连当前仍可能返回 `UPSTREAM_CHALLENGE`；浏览器代码与服务端接口的验证结果见 [BGM 来源调查](docs/BGM_SOURCE_RESEARCH.md)。成功下载并确认许可后，可上传音频作为 BGM。发送“配上轻快背景音乐”仍可使用内置原创合成配乐。发送“把口播加入成片”后，再发送“生成成片”。背景音乐在导出时循环并降低音量，口播与原声可同时混音。封面会用于 H5 的成片预览卡片，原图与成片版本一同保存在服务端。
5. 预览、进入剪辑拼接页查看时间线，从成片库下载对应版本的 MP4。导出失败可重试。

所有剪辑和生成请求都由对话发起。页面里的快捷操作只填写指令，发送后才执行。服务端用 `@earendil-works/pi-agent-core` 的 Agent Loop 规划内容，FFmpeg 负责确定性剪辑与音轨合成。剪辑 Agent 可读取素材信息、切镜点及通过 Seed 2.1 Lite 分析的原声逐字稿，没有源视频画面语义理解能力。成片审查单独读取成片音频和三张抽帧。

## 原声理解与口播精剪

在素材库点击“理解原声”，或附加素材发送“转写这段口播”。后台的音频理解模型须启用 Seed 2.1 Lite 并配置 API Key。升级旧配置时，会从已配置官方 Ark 模型复制加密密钥到新条目，管理员可以单独修改。输入音轨转为 16kHz 单声道 WAV，按最多30秒分块，缓存成功块，再按完整逐字稿重建跨块句子边界；无音轨视频直接返回 no-audio。逐字稿 JSON、字词源时间、句子完整性和低音量停顿保存在 `data/audio-understanding/`，素材库可查看和下载。时间码由模型估计，格式及范围校验不代表强制对齐或人工核验。

可发送：“精剪约30秒，删重复和重录，保留完整原话，加字幕、关键词叠字和轻微推镜，保留原声，不要配音，直接导出。”运行时加载 `qingjian-audio-understanding`、`qingjian-talking-head-edit` 和 `qingjian-render-review` 三个 skill；字幕先按语义短语分行，再按所选字词映射，精剪只接受已标为完整的整句。时间线执行字幕、缩放、覆盖层、片段音量、三路混音、响度归一化与 cut/fade 转场。

修改请求先更新并校验方案再导出；纯“导出当前方案”复用当前版本。成片审查检查文件时长、音轨、画幅、方案哈希、字幕、所要求的效果、人声响度，再提交完整成片音频和20%/50%/80%抽帧进行语义评分。可修复的遗漏最多自动返修一次，仅接受检查和评分不变差的结果；未通过或模型调用失败时显示“仍需复核”。自动评分不等于人工逐帧审阅。新增观点强调、观点对比模板以及关键词强调、下三分之一提示、章节进度、对比揭示动效。

`pnpm test` 执行意图路由、逐字稿校验、完整句子、修改时长和真实 FFmpeg 渲染回归。

## Agent 能力评测

管理后台的「Agent 能力评测」提供热点新闻、知识科普、多素材剪辑三类九个初始用例，可编辑指令、绑定评测视频、批量运行及重复测试。运行复用真实 Agent、联网研究、配音和渲染链，保存用例版本、素材哈希、模型与代码/skill 指纹。历史可查看失败原因、成片与工具调用，记录独立人工评分，导出报告并比较同一用例的基线分数；生成文件和质量通过分别统计，声音检查失败不会被隐藏。评测文件仅在管理员权限下读取，不上传公开 OSS。使用方法、评分与限制见[评测说明](docs/AGENT_EVALUATIONS.md)。

## 当前范围

- 帐号数据保存在服务端，同一帐号可跨设备继续创作；API 仅监听 `127.0.0.1` 并由 Nginx 提供 HTTPS 入口。新帐号注册需通过 Resend 邮件验证码；当前未提供自助密码找回或存储配额。
- 一次最多上传 6 个视频、图片或音频，单文件最大 300 MB；图片支持 PNG、JPEG、WebP，音频支持 MP3、WAV、OGG。剪辑方案最多 32 个片段、60 秒，支持 9:16、16:9、1:1。视频分镜最多展示 8 段。
- 对话中的生成任务按消息意图执行。复合请求如同时生成口播和图片，建议分两条消息发送。
- 封面作为 H5 预览海报保存；当前 MP4 文件本身不嵌入封面图作为首帧。
- 文本模型可在后台添加不同厂商的兼容模型；图片和音频生成目前使用内置的火山服务协议，后台可调整模型 ID 与官方服务地址。
- 配置 OSS 后，素材、生成图片、口播音频、成片、封面和分镜缩略图持久保存在 Bucket；`data/` 保留 FFmpeg 处理缓存与帐号/任务状态。设置 `OSS_PUBLIC_READ=true` 时，图片、视频和音频预览使用可匿名访问的 OSS 直链，下载仍走需要登录的应用接口；知道直链的人可以直接读取对应对象。旧数据可用 `pnpm tsx scripts/sync-oss.ts` 迁移。未配置 OSS 时使用本地存储。删除素材可能使引用它的方案无法再次导出，已生成的成片版本仍可下载。
