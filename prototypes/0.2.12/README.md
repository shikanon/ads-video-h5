# 轻喵 0.2.12 第二个 Tab 原型

最新范围：只调整第二个“工具”Tab。原版“创作 / 工具 / 资源 / 我的”四个 Tab 的名称、顺序、图标和职责保留。“创作”“资源”“我的”页面不改，既有功能和用户数据不改。

原型使用原版四个导航图标。其他 Tab 仅表示原版入口，不在这里重画页面。原版 WXML、WXSS、JS、app.json 均没有改动；本阶段仍是独立原型。

第二个 Tab：顶部工具名与设置、中间画布、短状态、当前主按钮、输入框、可折叠模板。删去介绍段落、副标题、教学式长文和重复说明。只保留短标签、常用按键、当前阶段积分及必要的错误原因。

轻喵模板继续按“上传角色 → 两种画风 → 3张样张 → 确认整套”执行。静态 / 动态为输出设置。参考图不可用时显示具体短原因与重新上传按钮。切换模板保留之前的草稿和画风。

当前主文件 `canvas-tools.template.html`；`build-prototype.py` 生成自包含的 `workbench.fragment.html` 和对话内预览。先前的三 Tab、大范围导航重组和步骤页方案已撤回，旧文件仅用于追溯。

按两张手绘图落实：左侧“表情 / 视频”分类；生成结果作为独立节点放在画布，可拖动、缩放、调整大小和移除（可撤销）；独立 Agent 对话记录；输入框；可展开模板面板；视频模板按剪辑、图解、口播分类。点模板只带入可编辑提示词，不生成、不清空已有产物；用户点发送后才推进对应流程。

最新原型固定为手机竖屏：390×844，窄屏自适应至320宽。即使在桌面预览也保持手机比例，不再展示760宽的平板布局。画布与独立Agent记录上下排列，左侧分类和原版四个Tab保留。

模板使用原版资产作为“静态例图 + 短名称”卡片；“展开”显示双列。轻喵卡片使用24张原版橙发表情中的01、03，视频模板使用各自原有poster.png。来源与SHA记录在 TEMPLATE-IMAGE-SOURCES.json。禁止把用户生成结果、QA验收图片或新绘制的图当作模板例图；没有原版例图的工具直接标注“暂无例图”。

移除了画布下常驻的轻喵提示面板，点模板只在输入框填提示词，不追加对话、不生成产物。对话记录仍可按需从图标查看。初始画布为空，生成后的演示产物只在用户实际点击发送后出现，不能预先充当模板效果图。

最新修订：移除原型自行添加、没有原版例图的“文字表情”入口。模板改用56×56的小图标与短名称，不再使用大卡片；轻喵图标使用原版24张中的01，选择后仍进入原有的两种画风流程。展开面板同样使用小图标排列。

视频提示词按原模板功能完善：界面动效的触发/反馈/结果、原理拆解的输入/变化/输出、空间发布的三层空间与产品价值点、AI前沿图解的来源查证与紫粉图解。用户填写项和原有制作规则由 video-prompts.json 管理，时长、画幅、尺寸、帧率、旁白与配乐直接读取各原版 template.json，避免手写参数漂移。输入框支持多行编辑，选模板只填词，不执行制作、不追加说明区。

所有图片为既有验收示意素材；生成、积分和导出均为本地模拟。未部署、未上传微信。
