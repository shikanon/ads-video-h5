# 轻喵 0.2.9 本地迭代

以已合并的 0.2.8 提交 `9d8e0e5` 为基础，调整小程序导航和模板展示。

- 底部导航为「创作 / 模板 / 资源 / 我的」。
- 模板使用服务端目录中的名称、说明、skill 关联及样片，以首张宽卡和后续双列卡展示；点击查看详情、预览样片或选用。
- 重新进入模板页、下拉刷新时同步目录；技能筛选展示已注册为模板的 skill，不暴露内部技能文档。
- 模板通过 Tab 进入创作草稿，保留文字和附件；不自动提交制作。对切换账号、切换会话和迟到的目录响应做隔离。
- 「资源」页内切换素材与成片，两边保留独立的搜索、类型筛选与分页。素材上传、镜头归档、制作归档，以及成片预览与运行任务入口保留。
- 老成片页面入口自动转到资源页的成片分区；原生 Tab 图标同步适配两套主题。

后续新增 skill 时，沿用现有 `skills/<id>/SKILL.md` 与 `template.json` 注册方式；模板页读取后端 `/api/templates` 目录。更新并部署后端目录后，重新进入模板页或下拉刷新即可同步。可选样片继续沿用既有公开样片接口，无须把技能指令正文打包到小程序。
