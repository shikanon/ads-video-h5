# 0.3.1 本地验收

- 空白「对话」检查模板按钮在输入框上方纵向排列。点击框内淡色提示，句子成为可编辑草稿，点击发送键后才提交。点「输入」可从空白开始，返回「对话」时避开上一次的提示。
- 「工作」页检查制作输入、进度和产物，模板和淡色建议入口集中在「对话」页。
- 在对话侧栏底部分别点头像、昵称，检查两个编辑入口及保存后的显示。头像行右侧打开「设置」，登录后可在设置页底部退出登录。
- 在侧栏「全部」旁查看会话总数。打开某条会话的三点菜单时，检查底色只出现在该按钮上。
- 在对话侧栏点「技能」，检查侧栏收起并打开技能列表。选中技能后，应填入当前对话的草稿。
- 检查底部依次显示「工作台」「轻喵对话」「资源」。在「资源」里点积分卡进入明细与签到。未登录时，点积分卡可打开新版登录页。
- 在「资源」分别点「素材」和「成片」，检查各自的搜索、列表与预览，返回后可打开另一个入口。
- 用「＋」选择一张自己的角色图。发送「@表情包动画视频」后检查候选画风、动作样张、确认整套，以及成片和 GIF 或 PNG。
- 发送「@知识科普动态图视频」和主题，检查成片回到对话。用「@音乐MV」检查素材文件夹、音源、时长、清晰度、费用预估与中间片段。
- 在工作会话发送「写笔记」「查看笔记」「找素材」「批量制作」「查看批量项目」和「查找项目」，检查相应入口。检查「对话」中的原有模型、联网和语音入口。
