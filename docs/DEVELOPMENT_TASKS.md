# 轻剪开发任务清单

依据 [PRD](PRD.md) 拆分。完成标准以真实素材和真实服务端结果为准；示例画面、演示规则及未接通的按钮不能计为验收通过。

| 编号 | 工作包 | 交付内容 | 验收证据 |
| --- | --- | --- | --- |
| T01 | 数据与任务模型 | 会话、消息、素材、剪辑方案、口播、图片、导出版本和异步任务持久化；刷新可恢复 | 重新打开页面后对象与状态一致 |
| T02 | 素材接入 | 视频/图片上传、预览、移除；输入框附件与素材库选择 | 真素材可进入对话，非法文件和超限显示错误 |
| T03 | 对话式 Pi Agent | 使用可配置默认文本模型运行 Agent Loop；受校验工具生成/调整方案；聊天触发导出 | 连续消息可修改指定片段，生成指令创建任务 |
| T04 | 口播 | 对话生成文案和独立音频，试听/下载/重试；可按指令加入视频 | 音频文件可播放，合成后视频包含口播 |
| T05 | 图片 | 对话生成图片，预览、保存素材库、再次调整并用于方案 | 真图片可打开，失败可重试且不丢失原结果 |
| T06 | 成片 | FFmpeg 校验、拼接、导出，版本保留与下载 | 生成 MP4 可播放、下载，旧版本仍可访问 |
| T07 | 移动端 H5 | 对话工作区、Logo 菜单、素材库、成片库、历史、时间线预览、设置/用户中心 | 核心旅程在手机视口和桌面可完整操作 |
| T08 | 管理后台 | 受保护的本地管理入口；模型厂商/用途/模型 ID/API Key 配置；密钥只在服务端存储与使用 | 可添加/更新/禁用模型；API 响应不泄露完整密钥 |
| T09 | 体验与异常态 | 上传失败、无素材、模型不可用、生成失败、任务重试、弱网提示；键盘与安全区适配 | 异常态可恢复，用户草稿和已有结果保留 |
| T10 | 交付与验收 | 构建、端到端旅程、移动端视觉检查、完成度差距记录、使用文档 | 可复现的验证记录和明确的剩余限制 |
| T11 | 分镜识别 | FFmpeg 检测切镜点，生成镜头时间段与代表帧；Pi Agent 可按镜头边界规划片段 | `docs/test.mp4` 检出 8 段，前 4 段按序进入方案与成片 |
| T12 | 背景音乐 | 支持上传 MP3/WAV/OGG，或对话选择内置轻快合成配乐；导出时循环、调低音量并与原声/口播混合 | 成片 MP4 含 AAC 音轨，元数据记录 `hasBgm`，时间线显示背景音乐 |
| T13 | 远端测试部署 | 独立 systemd 服务、Nginx `/qingjian/` 路由、访问控制与数据盘存储；保留原有网站 | 远端上传、对话方案、导出下载、异常态与移动端浏览器验收通过 |
| T14 | BGM 来源搜索 | 本地浏览器抓包及无凭据重放；Pi Agent 提取搜索词，提供 Pixabay/24bit 原站入口；校验并导入用户提供的 Pixabay 单曲 MP3 链接 | 本地与远端均可搜索入口、导入并混音导出；站点自动搜索 API 被 403/522 阻断，记录为未完成依赖 |
| T15 | 帐号与页面 | 暖色 Landing、登录、注册；密码哈希与 Cookie 会话；按帐号隔离会话/素材/任务/成片/设置；用户中心改密和退出；旧数据安全归属 | 双帐号接口隔离、本地页面交互、线上登录及旧数据/成片下载通过 |

并行边界：服务端 Agent 与媒体任务、移动端 H5、管理后台分别开发；统一使用 `src/types.ts` 的响应模型。集成时以服务端状态为准，不在浏览器保存 API Key。
