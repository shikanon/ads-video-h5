# Agent 能力评测

管理后台 `/admin` 的「Agent 能力评测」可维护评测集，运行真实 Agent 制作任务，查看成片、失败原因、工具记录和人工审阅。每轮评测使用独立会话，不出现在普通帐号的会话或素材列表中。

## 开始评测

1. 在模型配置中启用文本与音频理解模型；热点、知识视频还需启用音频生成模型。
2. 进入「Agent 能力评测 → 评测集」，勾选用例。多素材用例先上传真实视频，再在「配置用例」中绑定至少两段素材。
3. 填写评测名称，选择文本模型及每例重复次数，点击「开始评测」。未指定文本模型时使用当前默认模型。
4. 在「评测历史」查看阶段、耗时、完成率和通过率。打开单例结果，可播放、下载成片，展开检查项及真实工具调用记录，并保存人工分数与意见。
5. 选择历史基线比较同一用例的自动分数，或「导出本轮记录」保存 JSON。

模型调用、联网研究、音频生成和渲染会实际执行，并产生对应的服务费用与运行耗时。关掉页面不停止任务；「停止评测」会取消当前及后续用例，并终止当前用例的模型请求和本地渲染。服务重启会将未完成运行标为中断，须重新开始，不自动复用旧模型快照。

## 内置评测集

初始提供三类共十八个成片用例；指令和预期可编辑，也可新增用例。升级会补入缺少的新内置用例，保留用户修改、停用状态和历史快照。编辑会增加用例版本，不改变已经保存的历史运行。

| 类型 | 用例 | 重点 |
| --- | --- | --- |
| 热点新闻 | 今日 AI 热点解读，45 秒竖屏 | 真实检索、时效、来源、因果图解和紧凑旁白 |
| 热点新闻 | 机器人新闻的事实与观点，45 秒竖屏 | 近三天报道、数字查证、事实与推论 |
| 热点新闻 | 选题到成片，两轮指令，35 秒竖屏 | 先选题，再正确解析「第一个」并制作 |
| 知识科普 | 损失函数变迁史，默认四分钟横屏 | 简短原始指令、概念递进、公式、演算 |
| 知识科普 | 交叉熵的直观解释，45 秒横屏 | 零基础解释、数值例子、概率图解 |
| 知识科普 | RAG 与微调的选择，60 秒横屏 | 对比、适用场景、流程动画和限制 |
| 多素材剪辑 | 两段素材的原声剪辑，20 秒竖屏 | 实际使用多个指定素材、字幕、原声和音量 |
| 多素材剪辑 | 口播选句与论证，35 秒竖屏 | 删除重复、原话、源时间码、选择理由、完整句子 |
| 多素材剪辑 | 修改方案后重新导出，两轮指令 | 从 20 秒竖屏改为 15 秒横屏，核验最终新版本 |
| 新闻指令回归 | Fable5.5 原始指令、礼貌问法、换行、明确无素材 | 零附件创作、名称版本不换题、显式横屏、紧迫氛围 |
| 新闻指令回归 | 航天新闻、先分镜再授权出片 | 更换领域、自主查证、不编造现场、保留多轮限制 |
| 知识指令回归 | 重构量子计算、儿童光合作用、中文时长的月相讲解 | 从零重构不误要真人素材，问法也能执行，四十五秒不回落到默认时长 |

多素材用例没有绑定素材时不能运行。素材内容应适合用例主题，并有可剪出的完整句子；上传不合适的素材同样可能导致真实能力评测失败。

## 评分与判定

自动分数是执行要求的加权完成分；模型对成片的语义审查分数另保存在成片审查记录中。默认门槛为 80 分，且所有适用检查都须通过。即使总分达到门槛，任一检查失败仍显示「需要复核」。

| 检查 | 默认权重 | 实际依据 |
| --- | ---: | --- |
| 真实成片与制作记录 | 15 | 文件实际可读、SHA-256、可执行方案和渲染清单哈希一致 |
| 目标时长 | 10 | 实测视频时长与用例容差 |
| 画幅 | 5 | 方案、产物画幅及真实文件检查 |
| 字幕与时间码 | 10 | 已执行字幕及成片字幕核验 |
| HTML 图解／多个指定素材 | 15 | 真实生成分镜哈希／时间线实际使用的上传源素材 |
| 解释递进／原话与精剪证据 | 10 | 钩子、目标、前置概念、总结／原话、源剪点、选句理由 |
| 事实与来源／多轮执行 | 10 | 新闻时效与发布者、知识事实审查／最终修改版本 |
| 关键内容覆盖 | 5 | 实际选中音频范围的转写，不用未选中的整段逐字稿冒充 |
| 声音 | 10 | 实际音量、响度、音色与旁白相关检查全部通过 |
| 成片综合审查 | 10 | 原有成片审查通过、达到门槛且无失败检查项 |

自定义用例额外要求 HTML 重构或仅原声时会增加对应检查，总分按适用权重归一到 100。人工分数和意见独立保存，不覆盖自动分数、失败状态或原检查项。

「成片完成率」为有实际成片的次数／本轮总次数；「质量通过率」为通过次数／本轮总次数。失败、中断、取消仍计入分母。没有成片时不给假分；自动均分仅统计已经评分的成片，需结合失败数和完成率解读。整轮「已完成」只表示所有用例已经结束。

自动审查沿用现有文件检查、完整音频和有限关键帧语义审查，不能代替逐帧人工审片。节奏、事实表述和画面教学效果仍应人工复核。热点用例的新闻会随运行日期变化，不宜把跨日期分差直接当成 Agent 改进。

## 可复现记录与隔离

每轮冻结文本、音频生成、音频理解及图片模型配置，记录模型 ID、厂商、代码与 skill 指纹、评分规则版本。运行期间更改后台模型配置不影响本轮；API Key 只留在服务端内存，不进入评测报告。

每例保留原始各轮指令、用例版本、预期、素材哈希、任务 ID、工具输入输出、耗时、失败原因及实际成片哈希。工具记录不包含模型内部思维链。同一评分规则、指令、预期、门槛及素材内容的用例才比较基线分数；改动这些内容会生成新的用例指纹。

评测输入和产物采用专用归属标识。管理接口与播放器文件均要求独立管理员登录会话，不使用 URL 中的令牌，不上传到公开 OSS。普通帐号访问不到评测会话及文件。

配置、历史与输入素材保存在 `data/evaluations/`，真实会话、任务和产物继续使用 `data/app-state.json` 及现有媒体目录。备份时需同时备份这些目录。当前单轮最多选择 30 例，每例重复 1–3 次、总计最多 60 次；单例默认时限 30 分钟。单视频最大 100 MB，每例最多六段；最多保留 200 个用例、100 段素材、100 轮历史，达到上限明确阻止新增，不自动删除历史。

## 实现与回归

`server/evaluations.ts` 管理用例、历史和执行生命周期，`server/evaluationScoring.ts` 负责判定；`server/index.ts` 的适配器复用普通对话的意图路由、后台队列、Agent、模型和渲染工具。评测没有单独伪造的视频生成链。调度管理类指令会被拒绝，防止评测创建持久定时任务。

`tests/evaluations.test.ts` 覆盖用例契约、文件名、评分证据、真实 FFmpeg 文件及清单、版本快照、模型隔离、私有存储、失败后继续、停止竞态和重启中断。接口见[接口契约](API_CONTRACT.md)。

## 快速指令回归和可观察诊断

另有 `tests/fixtures/agent-requests.json` 的 74 条指令契约，覆盖礼貌问法、主题前置、换行、全角字符、中英混用、中文时长、无素材创作、只写脚本、只查资料、只解释流程、原片剪辑、后续修改和授权变更。题材包括模型新闻、机器人、航天、气候、产品介绍、量子计算、光合作用、月相、垃圾分类和地震避险。每例明确预期路径、是否出片及适用的主题、时长、画幅、情绪、配乐约束。

```bash
pnpm test
pnpm eval:requests
pnpm eval:requests --live --models all --out data/request-evaluations/routes.json
pnpm eval:requests --live --probe --models all --out data/request-evaluations/semantic-probes.json
```

默认只运行生产规则，需要语义判断的用例标记为 `deferred`，不算通过。`--live` 使用已经配置的真实文本模型，调用与线上相同的 `planCreationRoute`；`--probe` 则对每例实际调用语义路由工具，记录工具校验和重试。可用 `--family planning` 等限制用例组，或 `--models ark-text-deepseek` 指定一个注册模型。真实模型调用会产生费用；这些命令不执行联网研究、TTS、画面生成或渲染，因此成绩是**指令路由通过率，不是成片质量分**。报告保存代码和语料指纹，不能把尚未执行的样本计为成功。

生产任务会记录 `plan_creation_route`，包含用户请求、选定源素材数、当前方案状态、选择的路径、出片授权及简短依据。评测结果还保留 `diagnostics`：参数错误、缺少源素材、上游失败、审查反馈及后续实际恢复。`qualityFeedback` 单独记录审查驳回和局部返修，审查接口不可用保持待复核。恢复一次工具调用不代表成片验收通过。

这些记录用于探查可观察的执行过程，不采集或展示模型内部思维链。工具输入输出会屏蔽凭据、媒体载荷和隐藏推理字段。`tests/requestRouting.test.ts` 的受控模型响应测试与真实模型探测分别报告；故障注入实际驱动 Pi Agent 和教学工作流，覆盖无效脚本、HTTP 503、事实驳回、局部修复、不越过只写脚本的授权，以及三个模型各自要求的调用参数。

解释和澄清回复还验证一次有效工具提交后立即结束、空回复按真实工具反馈修复、连续无效回复最多三轮。生产回复同时有 60 秒时限，避免强制工具调用导致任务一直运行。

素材隔离也覆盖解释和澄清阶段：通过与生产相同的 `answerForSessionWithPi` 调用，验证新会话不会把历史生成分镜或未选定上传文件传给回复模型，当前附件、已选方案源素材和本会话历史附件仍可使用。
