# 轻剪 H5 · 产品需求文档

版本：原型整合稿（2026-09-25）

## 1. 产品目标与范围

轻剪面向希望快速制作短视频的用户。用户在 H5 中添加本地视频和图片，用对话描述成片要求，查看剪辑方案与预览，可进一步生成口播文案和独立音频，进入时间线调整片段，最后生成并下载视频。界面保持暖白底色、石墨色文字、珊瑚橙主操作色和移动端单列布局。

**实现状态：**本文描述四张原型图对应的目标体验。当前仓库已实现视频上传、文字对话生成片段方案、FFmpeg 合成 MP4、预览和本地下载；Pi Agent 的真实模型调用需配置服务端密钥。图片附件、口播音频、时间线编辑、Logo 菜单及其子页面仍是待开发需求，不应在验收时视为已有功能。

## 2. 信息架构与 Logo 菜单

首页顶栏的「轻剪」Logo 是菜单按钮。点击后从左侧弹出菜单抽屉，页面其余区域出现半透明遮罩；再次点击 Logo、点击遮罩、选择菜单项或按返回键时关闭菜单。菜单显示当前页面的选中状态。若用户在剪辑页有未保存的修改，离开前提示保存或放弃。

| 菜单项 | 页面与主要内容 |
| --- | --- |
| 新建剪辑 | 返回对话首页，开始新的素材与剪辑会话。 |
| 素材库 | 按视频、图片、音频查看已导入素材；预览、选择加入当前对话、移除素材。 |
| 成片库 | 查看已生成的视频及版本；播放、进入剪辑拼接页、下载。生成中的任务显示状态。 |
| 对话历史 | 查看并继续已有剪辑会话；保留每次会话关联的素材和方案。 |
| 用户中心 | 展示用户资料与登录状态；访客状态提供登录入口。 |
| 设置 | 设置默认画幅、导出清晰度和音频偏好；修改后仅作用于新方案或下一次导出。 |

菜单中的素材库、成片库和历史记录应有明确空状态与返回首页入口。删除素材或成片时需确认，并说明是否会影响已有方案或导出文件。

## 3. 核心流程

1. 从首页添加视频；也可从「素材库」选择已有素材。
2. 在底部输入框描述要求，可附加本地图片作为封面或视觉参考。发送后，图片缩略图与文字一起进入对话消息。
3. Pi Agent 根据用户要求和可用素材生成结构化剪辑方案；界面显示片段顺序、时长、画幅与视频预览。
4. 用户可在对话中要求生成口播。页面返回可阅读的口播文本，并生成独立音频供试听和下载。
5. 点击视频预览或成片卡片，进入「剪辑拼接」页调整片段与口播音轨；保存后重新生成成片。
6. 成片完成后可播放、下载到本地，并在「成片库」中找到对应版本。

## 4. 原型图与页面需求

### 4.1 对话首页与成片预览

首页依次展示顶栏 Logo 与历史入口、素材区、对话区、片段轨道、视频预览、生成与下载操作，以及底部常驻输入框。素材不足时使用明确的示例标识；只有实际生成完成后才开放下载。点击视频预览进入剪辑拼接页。

![轻剪对话首页原型](h5-concept.png)

### 4.2 输入指令并附加本地图片

输入框的图片按钮可从本地设备或素材库选择图片。附件在输入框**内部**显示缩略图、文件名、来源和移除按钮；文字指令与附件可同时编辑。发送前移除附件不会删除素材库中的原文件。发送失败时保留已输入文字和附件，便于重试。图片作为封面或视觉参考的用途由用户指令确定，不能默认为视频片段。

![输入指令与本地图片附件原型](h5-input-with-image.png)

### 4.3 口播文案与独立音频试听

口播结果分为「口播文案」和「独立音频」两个对象。文案完整可读；音频卡片显示文件名、播放/暂停、进度、时长和下载入口。用户可先试听独立音频，再决定是否把它加入成片。音频生成中、失败和可播放状态需分别显示；音频失败不应丢失已生成的文案。

![口播文案与音频试听原型](h5-narration-audio.png)

### 4.4 点击视频进入剪辑拼接页

剪辑页提供视频预览、播放控制、时间刻度、片段轨道、选中片段的裁剪手柄、播放头和独立口播音轨。底部工具包含裁剪、分割、排序、配音。用户的操作应立即更新方案与预览；点击「保存并生成」后创建新的成片版本，并在成片库中可见。返回上一页时保留已保存的方案，未保存修改需提示。

![视频剪辑拼接页原型](h5-edit-timeline.png)

## 5. 功能验收要点

| 功能 | 可观察的验收结果 |
| --- | --- |
| Logo 菜单 | 点击 Logo 显示上述六个入口；遮罩、返回键和导航行为正确；当前项有选中状态。 |
| 素材库 | 视频、图片、音频能分类查看；选择图片后，输入框内出现正确缩略图与文件名。 |
| 对话方案 | 方案只能引用真实素材，片段时间不越界；用户继续提要求可得到新方案。 |
| 口播输出 | 文案可阅读；独立音频可播放、暂停、拖动进度并下载；失败可重试。 |
| 剪辑拼接 | 可选中、裁剪、分割、排序片段；播放头和预览随编辑变化；口播音轨与视频时间线对齐。 |
| 成片库 | 生成中显示任务状态，成功后能预览、再次编辑及下载对应 MP4。 |
| 用户中心与设置 | 入口可访问；访客状态明确；默认设置在新建方案或再次导出时生效。 |

## 6. 数据与实现约束

- 核心对象包括素材、对话会话、消息附件、剪辑方案、口播文案、独立音频、导出任务和成片版本；素材 ID 与成片版本应稳定关联。
- Pi Agent 运行在服务端，负责理解对话并调用受校验的工具；FFmpeg 与音频合成由确定性的服务执行。模型密钥不进入 H5。若尚未接入画面理解能力，不能声称已自动识别真实“精彩镜头”。
- 浏览器上传进度和服务端生成进度分别展示。视频与音频合成应作为可查询、可重试的异步任务，离开页面后可从成片库继续查看。
- 当前单机原型限制为一次最多上传 6 个视频、每个 300 MB；剪辑方案最多 8 个片段、总长 60 秒，支持 9:16、16:9 和 1:1。账号、跨设备同步及生产环境存储需在用户中心与素材库上线前另行设计。
