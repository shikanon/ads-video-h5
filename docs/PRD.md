# 轻剪 H5 · 简要 PRD

## 1. 产品目标

让没有剪辑经验的用户在手机浏览器上传自己的视频，用自然语言说明时长、画幅和节奏，得到一份可执行的剪辑方案，并下载实际生成的 MP4。

## 2. 核心用户流程

1. 进入 H5，看到对话示例与成片预览示例。
2. 上传一个或多个本地视频，页面展示素材、时长和原素材预览。
3. 输入剪辑要求，例如“把旅行素材剪成 15 秒竖屏短片”。
4. Pi Agent 调用 `propose_edit` 工具输出片段顺序、起止时间、画幅和说明；页面展示方案。
5. 点击“生成成片”，服务端用 FFmpeg 裁切、缩放、拼接并生成 MP4。
6. 预览成片，点击“下载视频”保存到设备。继续对话可重新生成方案和成片。

## 3. MVP 功能与验收

| 功能 | MVP 验收 |
| --- | --- |
| 素材上传 | 最多 6 个视频，每个不超过 300 MB；无效视频显示明确错误。 |
| 对话剪辑 | 支持自然语言描述；有模型密钥时使用 Pi Agent 的工具调用；无密钥时显示演示模式。 |
| 方案校验 | 片段必须引用真实素材，时间在素材范围内，1–8 段，总时长不超过 60 秒。 |
| 视频导出 | 支持 9:16、16:9、1:1；输出可播放 MP4，保留可用源音轨。 |
| 本地下载 | 仅在成片生成成功后开放下载入口。 |

## 4. 交互与视觉

移动端单列页面：顶栏、标题、素材区、对话区、片段轨道、预览播放器、生成和下载按钮，以及底部常驻输入框。使用暖白底色、石墨色文字与珊瑚橙主操作色。示例画面和实际素材有清楚标识。设计图见 [h5-concept.png](h5-concept.png)。

## 5. 技术方案

- React + Vite 构建 H5；Express 提供上传、对话、导出和下载 API。
- Pi Agent 运行在服务端，模型只接收对话文本、素材文件名和时长；`propose_edit` 工具返回结构化方案。
- FFmpeg 执行视频裁切、统一编码、画幅适配和拼接。
- 本地 `data/` 保存素材、方案及成片；不上传原视频到模型服务。

## 6. 当前边界与后续

当前版本不做画面语义识别、智能踩点、自动字幕、背景音乐或账号系统。用户说“选最精彩画面”时，模型无法仅凭文件名和时长可靠判断内容。后续可增加镜头检测与语义索引，再接入异步任务、导出进度和多用户存储。真实模型路径需配置服务端密钥后做一次端到端验收。

图片附件输入、独立口播音频试听和时间线剪辑的后续界面草案见 [功能展示视觉稿](UI_STATES.md)；这些功能尚未包含在当前 MVP 中。
