# 视频 Agent 的主动执行与恢复测试

测试对象包括新闻、知识、产品介绍、教程、活动宣传、历史叙事、城市介绍以及已有素材剪辑。所有测试记录应区分以下三层，不能用理解指令正确代替出片成功。

| 层级 | 入口 | 通过标准 |
| --- | --- | --- |
| 指令理解 | `pnpm eval:requests` | 正确创作路径、主题、时长、画幅和出片授权；明确保留原片时不得自行换成新画面 |
| 故障恢复 | `pnpm test`、`pnpm eval:recovery` | 空回复后调整提交方式，错误参数后修正，临时故障后沿用有效状态，审查失败后实际返修，取消后不继续执行 |
| 实际生产 | `pnpm eval:production` | 真实来源、配音识别、图解、时间线、渲染和独立审查；成片通过后再验证完整播放和下载一致性 |

```bash
pnpm test
pnpm build
pnpm eval:requests --live --probe --models all --family general-creation --out /absolute/path/requests.json
pnpm eval:recovery --live --models all --fault all --out /absolute/path/recovery.json
pnpm eval:production --live --case general-product-thermos --through movie --out /absolute/path/product.json
pnpm eval:production --live --case tutorial-chart-30 --through movie --out /absolute/path/tutorial.json
pnpm eval:production --live --case promo-reading-30 --through script --out /absolute/path/promotion-script.json
```

真实评测从已配置的模型读取凭据；本机可通过命令前缀 `QINGJIAN_DATA_DIR=/absolute/path/configured/data` 指定既有配置目录。报告保留模型 ID、用例、实现哈希、实际耗时、工具输入输出及未通过的具体要求。`--probe` 会强制调用真实语义模型，不能把服务端规则的成功归入模型能力成绩。

`eval:recovery` 的模型决策是真实调用，素材转写、画面分析、渲染和审查是明确声明的控制夹具。恢复是否成功由完整工具链、原话保留、返修后的图形和执行次数判定；夹具内的审查分数不代表实际影片质量。英文普通主题允许经过明确列出的同义翻译；模型专有名称及版本仍须原样保留。

`eval:production --through script` 只证明查证、脚本及独立事实审查。`--through movie` 才执行实际音视频。`--resume` 复用同一请求检查点；图解模板变化会重新检查已核验语音的文件哈希，重绘、渲染并审查。需要复验旧检查点的图解时可显式使用 `--redraw --resume /absolute/path/checkpoint-directory`；报告会记录复用，不能声称进行了新检索或重新合成音频。

短片预算、研究入口、转写、画面分析、编排、渲染和审查由服务端推进。模型负责主题内容、选句和需要创造性判断的返修。重复无结果的素材检索会被关闭并推进到选句；连续空工具回复会改为结构化 JSON，再经过相同 schema 与事实/源原话校验。临时错误可以重试，认证错误、用户停止和不可证实的声明不能被当作通过。

研究失败的替代策略应保留用户主题，减少过细查询并尝试可读取的发布者资料。通用创作允许实际读取公开来源；`public-page` 表示读过正文，不自动代表权威。损失函数变迁史保留更严格的学术来源要求。每条事实仍需独立审查。

故障注入包含缺少工具调用、非法 sourceId、零匹配查询、反复读取、模型/渲染/审查 503、审查拒绝、较高分但仍被拒绝的旧版本、无音色授权的原声图解制作，以及执行中取消。可见图解必须呈现知识、对象或操作，不能把绘图任务清单显示给用户。报告保留失败结果，分母包含所有测试；本地工作流、浏览器验收和远程站点验收单独记录。

产品、活动、故事和程序绘制教程支持实际的通用 HTML 图解设计，经过数据校验、真实浏览器布局检查后渲染。画面返修不只在固定图标间切换。仅属于渲染缺陷的反馈可以沿用哈希核验的完整旁白，重新设计图形；事实、字幕、音色等问题仍走对应的返修。布局失败后会携带真实检查器报告和上一版布局改变设计；该重试有限制，不跳过检查。

数值柱状图支持结构化类别、数值、单位和坐标，程序计算柱高及刻度。非零基线只允许明确标记的并排截断示意；低于下限的值会保留原始数值并注明被截断，不能假画成零值。兼容旧检查点时只从已核验脚本里的明确数值标签提取，不给陌生主题套用固定示例数据。

本轮新增 24 条通用创作指令，指令库共 98 条；工作流入口 19 条；后台实际生产用例 30 条。覆盖换句式、多语言、多行指令、只要脚本、无原始素材自主绘制、已有素材原声保留等约束。

使用 `--redraw` 复用语音后，若后续审查要求改写内容，系统会重新合成受影响章节并保留新记录；不能将这部分称为原音频复用。

纯语音或字幕缺字问题直接重新核验或重录受影响章节，不强制改写正确脚本。恢复检查点时，已失效的脚本不能沿用旧事实评分；图解实现变更后重新建立一次有界验收周期。柱图数值卡片由已核验的数据计算数值和排序关系，不把动画时序备注显示在成片中。

2026-10-05 本轮结果：445 项测试通过，H5 和管理端构建通过。三模型各通过 24/24 条真实语义指令评测、2/2 条真实模型恢复评测。恢复测试的转写、渲染与审查采用明确标注的控制夹具；成绩不代表影片质量。普通英文主题允许明确的同义翻译，本轮也修正了过度字面化的评测别名，旧结果与新结果不能直接作模型能力增幅比较。

默认豆包的实际成片：保温杯介绍通过独立模型审查 82/100，30.05 秒、720×1280；柱状图教程最终交付版 85/100，31.97 秒、1280×720。时长门槛沿用生产审查的目标误差不超过 2 秒，未放宽；前一个教程版本评分 88，但浏览器检查发现可见动画备注，因此继续修正，交付成绩使用最终版本。阅读推广脚本独立事实审查 96/100，该项没有计入实际出片。

产品和最终教程均通过完整音视频解码，浏览器从头有声播放至 `ended=true`，首帧、中点、尾帧检查及下载文件 SHA-256 一致性核验；最终教程浏览器无错误日志。汇总证据保存为本轮评测目录中的 `agent-general-audit.json`，包含各层测试范围、实现哈希及所有实际生产尝试，失败记录未删除。

三模型测试证明本次指令理解和恢复样本通过；完整实际音视频目前验证默认豆包。产品和教程最后两次评测从检查点开始，复用记录与新生成记录均保留。所有失败尝试保存，不能用脚本通过、控制夹具分数或旧版本高分替代新成片验收。上述成绩为部署前的本地验收结果；远程发布须另外核对实际提交号和线上行为。
