## 核心用户旅程

1. 上传一段 4 秒旅行 MP4 和一张参考 PNG，发送“剪成 3 秒竖屏”的指令。Pi Agent 返回 1 个片段、9:16、3 秒方案。
2. 发送口播请求。文本模型返回“把温柔，藏进这场旅行里。”，音频模型返回约 3.9 秒 MP3；页面可播放、暂停、拖动进度并下载。
3. 发送“生成成片，并把刚才的口播加入视频”。FFmpeg 输出约 3.02 秒 MP4；文件同时包含 H.264 视频轨与 AAC 音频轨。浏览器的成片卡、剪辑拼接页和成片库可预览与下载。
4. 发送封面生成请求。文生图返回 JPEG；同一张参考 PNG 的图生图请求在延长模型等待窗口后真实返回 JPEG。失败后的重试沿用原消息与附件；完整应用中的重试产物为 700,186 字节 JPEG，预览与下载接口均返回 HTTP 200。
5. 继续说“把当前片段缩短到 2 秒”，Pi Agent 生成方案 v2；再发送重新生成成片，得到约 2 秒 MP4。v1、v2 文件均保留、可下载，且都有视频与音频轨。随后导出的 v3 保存了当时的方案快照和口播标记；从成片库进入时间线时显示对应的 2 秒片段与音轨。较早生成、没有快照的本机测试版本可播放和下载，并显示明确提示。
6. 选择参考图片并通过对话设为成片封面，后续导出版本保留独立封面文件。封面接口返回 HTTP 200 与原图 MIME 类型；H5 用它作为成片预览海报。只修改封面的指令不会自动导出。
7. 明确要求“把这张图片作为片段”，Pi Agent 将当前消息附加的生成图片放在视频片段之后，各占 2 秒；方案校验阻止误用素材库里的另一张图片。导出的 v5 为约 4.02 秒 MP4，含 H.264、AAC、2 个片段及独立封面文件。未明确要求图片进入视频时，图片仅可作封面或视觉参考。
8. 刷新页面仍能看到历史、任务和产物；独立服务重启后仍能读取并继续处理已保存任务。

## 体验验收

- **上手成本：**首页给出示例指令；添加素材后可直接输入自然语言。口播、封面和成片均在同一对话完成。首次使用需管理员先配置三个模型密钥，这一步目前通过独立后台完成。
- **移动端体验：**实测 320px 与 390px 宽度没有横向滚动；底部输入框常驻，附件缩略图、任务状态和媒体卡片在单列布局中可读。真实音频可在卡片内试听，视频以适合竖屏素材的方式展示。
- **交互流畅度：**提交消息立即返回任务并保持对话可用；离开页面、刷新后可继续看任务。参考图生成实测约 184 秒，长时间阶段只有任务状态与阶段进度，没有准确剩余时间。
- **完成度差距：**帐号密码登录和跨设备访问已上线，仍未提供邮箱验证、自助找回密码或批量数据删除。Agent 不理解画面内容；切镜基于画面变化，一条消息只触发一个主生成任务，需分步提出复合需求。用户协议与隐私政策页面提供原型说明，正式上线前仍需运营方审定正式文本。没有弱网节流条件下的专项时延数据。
- **封面边界：**封面在 H5 预览中显示并与成片版本一起保存，MP4 本身未将封面合成为首帧。

## 2026-09-26 分镜、BGM 与远端验收

- `docs/test.mp4` 为 30.05 秒、854×480 的 H.264/AAC 素材。上传后自动检测到 8 个镜头，分界点约为 2.75、5.13、10.83、13.63、19.08、25.25、27.88 秒；8 张代表帧均可经 HTTPS 打开。检测依据画面变化，不产生画面语义描述。
- Pi Agent 按指令选取前 4 个镜头，生成 16:9、约 13.6 秒的可校验方案；FFmpeg 顺序拼接并混入内置轻快配乐。实际 MP4 为 13.638672 秒、1,241,752 字节，包含 H.264 视频轨和 AAC 音轨，HTTPS 下载返回 200。单独上传 WAV 后，选择其作为 BGM 并重新导出也通过。
- 远端位于 `https://101.47.18.93/qingjian/`，Nginx Basic Auth 保护测试页面；管理 API 另由管理员 Bearer 令牌保护。API 与成片只在 `/qingjian/` 下，原有服务器首页继续返回 200。服务进程以 `qingjian` 系统用户运行，绑定 `127.0.0.1:8787`，数据目录权限为 700，令牌和加密模型配置文件权限为 600。
- 远端异常态：无 Basic Auth 的页面 API 返回 401；无 Bearer 令牌的管理 API 返回 401；不存在的镜头返回 404；伪装为 MP3 的无效音频返回 400，未进入素材库。
- Playwright 在 1365×900 和 390×844 视口验证页面加载、成片进入剪辑拼接页、背景音乐轨显示、素材库 8 张镜头图可见；无控制台错误和横向溢出。触发镜头卡片后，输入框预填含正确时间段的剪辑指令。
- 当前内置 BGM 是原创程序合成音，适合流程验收；正式创作建议上传用户授权的配乐。测试部署的共享访问密码不等同于正式多用户鉴权。
