# 自定义作者形象验收（2026-10-03）

结论：原图生成动画、已有序列帧导入、设定默认作者、Agent 编排、实际视频合成、页面播放与下载均在本地跑通。此次验收为隔离帐号与数据目录，不代表远程发布。

## 使用方式

1. 菜单打开「作者形象」，上传 Q 版 PNG/JPEG/WebP，点击「生成序列帧动画」。使用后台实际配置的 Seedream 5.0 Pro / Flash 图片模型或对应 Endpoint；透明 PNG 使用参考图透明背景生成。
2. 已有序列图可直接「导入序列帧」，填写网格和有效帧数。本次用户图片为 4 列、2 行、8 帧；默认每秒 6 帧，1.33 秒循环。
3. 点击「设为默认作者」，随后正常发出视频指令。普通剪辑显示为角标，横屏教学可使用侧栏。图像保存在帐号私有素材中，可下载、复用；不需要每次在指令中重述文件路径。
4. 说「去掉作者形象」更新当前方案；「停用」取消默认作者。普通知识教学已有时间线时，「重新导出」保留图解和旁白，生成新文件和新的审查。

一片最多一个作者动画。当前为眨眼、思考、点头等循环状态动画，尚无旁白驱动的口型同步。

## 动画和声音的检查

实际渲染采用透明 PNG 逐帧循环，不能把整张网格图作为静态画面贴入视频。主视频和作者序列使用明确的时间基准；全片作者由最终视频时长裁剪，避免重复的片尾开关造成漏帧。字幕最后烧录，保留原有音轨。

审查核对私有资产 SHA256、逐帧指纹、帧数、帧率、时间范围与布局，实际抽取作者区域连续 8 帧验证换帧，再检查片头与片尾的不透明人物区域是否与预期原帧相符。此像素检查用于执行验证，不是身份认证。

## 测试发现并修复的问题

- 静态图片拼接视频的主时间戳偏移，使作者在 8 秒成片的片尾提前消失。首次实际成片审查 78/100 抓到问题，修复时基后重新导出为不同文件；最终为 82/100。
- 教学片尾边界曾漏掉一个作者帧。新增实测首尾覆盖检查后发现；统一主视频与序列帧时基，并以成片时长裁剪全片作者，重新导出教学 v2。新文件片尾区域误差从 125.14 降至 8.33。
- 服务启动时会重写历史作品方案摘要，导致方案与渲染清单哈希不一致。历史 `Artifact.plan` 改为保留原样。两个最终文件在真实服务重启及页面切换后的方案哈希、作品哈希、清单哈希仍完全相同。
- 重导出静态图片时原有规划器要求再次声明图片用途。已有获准的图片时间线现在继承该用途；作者原图和序列图始终不参与视频源片段选择。
- 教学事实审查返回中文问题对象时，原有解析器丢弃修正要求。兼容章节、错误原句、依据、修复要求等中文字段，保留严格事实返修门槛；实际教学已继续完成联网查证、旁白、HTML/GSAP 图解和审查。

早期「阳光开场」模板测试证明作者能够进入 HTML 动效成片，但模板本身仅得 65/100：未实现要求的阳光效果，并有模板品牌残留。它保留为诊断记录，不作为本次最终样片，也不能据此宣称所有现有模板的视觉质量已解决。
