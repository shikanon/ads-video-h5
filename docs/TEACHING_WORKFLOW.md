# 从主题制作教学视频

在空白会话发送“生成一个从浅入深讲解损失函数变迁史的教学视频”，即可调用真实制作工具。从浅入深或变迁史默认240秒，一般教学默认180秒；16:9、1280×720；可在指令中指定15–600秒及其他画幅。无需附加源素材。新会话不会隐式读取帐号素材库；原声精剪、基于真人素材的重构继续走原流程。

`qingjian-teaching-video` skill 规定教学目标、知识依赖、事实证据、图解用途与声音验收。脚本校验一次反馈总字数、缺失图解和逐章主要问题，避免逐个错误消耗重试。Pi Agent 每步仅能调用当前阶段的工具：

`research_topic → write_lesson_script → review_lesson_script → synthesize_narration → draw_lesson_scenes → arrange_lesson_timeline → render_lesson → review_lesson`。

教学检索剔除二手博客，定向读取原始研究或教材网页摘录（`primary-page`），无法读取的实际检索引用标记为`search-cited`。逐条引用不能代替原论文全文核查。事实审查不通过会以`revise_lesson_script`定向修复涉及的章节，保留已经通过的章节及教学顺序；成片不通过可以调用 `repair_lesson`，重新制作、渲染并审查一次。不会因同一参考音、相同模型或任务完成而自动认定声音通过。最终保留分数较高且有真实产物的版本，并公开未通过项。

论文PDF实际提取的文本标为`primary-paper`，读取范围最多前16页并注明可能的数学排版误差；使用已有Python/pypdf，通过`QINGJIAN_RESEARCH_PYTHON`指定运行环境，依赖或下载不可用时不伪造摘录。`primary-record`来自实际读取的Crossref出版登记，只能支持作者、标题、年份等书目信息。初学者脚本的审查只依据本版内容，不把研究摘要里的所有扩展主题强行列为必讲项。

搜索失败时，可按包含用户身份、完整原指令及导出模式的检查点指纹读取24小时内的真实研究缓存；至少三条已核验来源，全部来源须有取得时间且在允许的原始来源范围内。缓存日期与本次搜索失败明确写入研究摘要和工具记录，本版脚本仍重新审查；不跨用户/指令复用，不以旧视频替代新的制作。

每章保留目标、前置章节、完整旁白、编排理由、具体事实及引用、图解数据、实际音频转写匹配率、动画触发时间、音频与HTML哈希。公式用Unicode SVG绘制；MSE、MAE、Huber、交叉熵、Hinge、Focal的曲线从受支持函数计算，拒绝执行模型提供的代码。GSAP暂停时间线由HyperFrames进行布局检查并真实渲染，分镜按实际语音时间触发重点高亮。

历史主题的时间线至少包含三个有引用的年份/年代节点，回顾旁白中提到的年份都须在画面中出现，允许将相关阶段合并在一张卡片。长公式解析外层除号为真正的分式，保留指数里的温度除法。实际浏览器测量SVG字宽，公式不低于28个SVG单位、图例不低于22；无法容纳时返修布局，不能截断或无限缩字号。教学分镜使用完整`hyperframes check`检查运行异常、布局、动效和对比度；旧`inspect`不捕获初始脚本异常，不能作为此流程的最终门槛。

声明以`basis`区分文献事实（`source`）、数学定义与演算（`calculation`）、综合教学推论（`synthesis`）。文献事实和综合推论必须关联真实来源；演算保存具体定义或代入过程，不借无关引用背书，且不能将历史年份、提出者或实验结论伪装成演算。独立审查仍须核算公式和数值。追加检索统一引用ID映射，最终作品只收录脚本使用的引用；官方文档的同站版本跳转也经过来源校验。

审查区分实际错误`findings`与非阻塞建议`suggestions`，80分门槛保持不变。高分但仍要求修复的争议在修稿后交由独立模型根据原句、数学定义和真实来源复核，保留首轮分数与全部意见；不能通过重复审查同一稿件碰运气获得通过。定向返修必须覆盖反馈涉及的章节，不能改写其他已通过章节或更改教学顺序。

成片语义审查也使用上述两类字段，页面展示非阻塞建议。任何实际缺陷或模型明确要求返修仍阻止通过；不能将错读、漏字或错误公式降为建议，也不会重写历史版本分数。

返修的原始要求单独保存在检查点`repairRequirements`，参数或校验错误只追加到反馈，不能改变原来涉及的章节范围。成片审查逐条注明章节ID，避免只改开场而遗忘公式、字幕或声音问题；实际HTML检查失败也会回到相应章节的返修阶段。

无真人参考时采用统一合成声线，第一章生成声音作为后续章节的参考，不冒充用户本人。规划保存`pacing`：普通讲解默认4字/秒，热点/紧凑短片4.6字/秒，明确慢讲3.2字/秒；支持用户指定每秒/每分钟字数，最新要求优先，“语速有些慢”按加快处理。字数不含标点，目标时长与内容字数一起规划，不能把稀疏稿件拖慢来凑时长。先按规划速率合成，再实测整体时长，仅在0.8–1.25倍范围内统一调整；合成偏离过大先重录，不能因此降低规划速率。使用真实ASR及实际音频时长核对字/秒，`voice`保存实测字数、秒数及字/秒；最终编码文件再次核对。字幕来自Seed 2.1 Lite对生成后音频的真实转写；错误年份、低匹配率、无法对齐的触发词会阻止继续制作。每段保留短安静首尾，短叠化位于安静间隙。

时间线独立校验保存的`pacing`模式、速率范围、停顿和缓冲值，并使用这套规划检查字数预算；不能因为时间线只收到章节与画幅，就重新套用普通讲解默认语速。

初稿的估计时长上限收紧到目标的112%，提前阻止明显过长脚本；真实旁白超出变速范围时，按实测字数/秒给出整稿字数预算，避免只改几个字后反复合成。首版成片之后的唯一一次自动返修有独立脚本/工具重试预算，首轮制作的校验失败不能耗尽该次返修；仍最多保留两次真实渲染的候选，按实际审查选优。

希腊字母在语音输入中展开为“德尔塔、伽马、贝塔、西格玛”等明确读法，画面保留符号。匹配识别其等价读法并核对实际符号内容；转写仅接收术语提示，不接收期望台词。字幕语义分行连续两次返回无效索引时，按真实字词、停顿及可读长度分行，保留全部词和时间码，且在转写警告中标明兜底；源字词本身的时间码或跨度无效仍会失败。

保守的同音术语规范化仅适用于旁白中明确存在的词，并保留听到的词的起止范围和`speech-analysis-raw.json`原始转写；缺失语音不能通过替换字幕补齐。连续四字未匹配、年份不一致或逐个小数不一致均触发重录。年份按“年”的语境检查，不把0.00013这种小数当作日期；小数位数减少或数值变化不能用整章高匹配率掩盖。

末尾四字必须与真实转写一致，额外尾词或漏字须独立复听，必要时重录。金额、百分比、台数、门店数及天/小时单位独立核对其数值与单位；“万元”漏成“元”、“百分之”漏成“百分”等问题不能靠平均匹配率放行，也不能直接用预期稿件补写字幕。

术语校正保留未修改的字词分组，并将字幕分行索引映射到新字词序列；保护希腊字母中文名、残差和完整小数，避免在换帧处拆词。仅整理文件首尾接壤的低能量空白（-55 dB），各保留0.12秒余量，原始音频另存，防止两段空白在转场处相加；段内停顿不删。处理后、变速/重录后的旁白及最终成片依据pacing实测长停顿：热点0.75秒、一般讲解0.95秒、慢讲1.25秒；段内超限后重录并核验，不截断语句或拉长静止画面。结构化审查的错误、证据和修正要求转换为可读反馈，原始响应同时留档，不因字段别名造成整项任务失败。

视频画面默认移除“轻剪课堂”、章节进度编号、内部ref编号及通用来源尾注。主题、实际图解、字幕和结论保留；事实引用仍完整保存在页面脚本及下载记录中。只有确有防误认或解释必要的数据口径、场景“示意”等内容标签需要进入画面。信息卡从第一帧可见，以位移和真实cue强调，避免空白缩略图及切入后才渐显正文。

“残差三时/伽马为二时”误识别成“三十/二十”时，仅在本章原句明确匹配的上下文中纠正同音字，并保留原始识别与实际时间范围。另行核对残差、误差、伽马和阈值数字，不能靠高整章匹配率放过3读成4；未计划的重复字必须重录或重新核验，不能直接删字幕。字幕的标点边界只从实际ASR里完整匹配的脚本短句映射，文字仍为实际ASR，未匹配的台词不补齐；长句按实际时间和词边界换行。

已匹配短句的开始和结尾均标记边界，包含冒号后的解释；实际停顿可补充分行。“损失零；零点五”不能被跨句的小数保护规则粘为“损失零零点五”。Focal 中的 `1−p_t` 在语音输入中展开为“一减去正确类别概率”，对实际转写独立核验减法顺序；“减一正确类别概率”必须核验或重录，不能改字幕掩盖读错。

关键数学术语“相似度”“概率变化”核对完整性及出现次数，不能以整章高匹配率掩盖漏字。术语或字词匹配存疑时先对同一音频独立复听一次，保留两版实际ASR；仍未通过才重录，不向ASR提供期望台词。短于三字的字幕尾部可并入同一短句前一条，保留所有实际文字及范围，不能跨已确认句子边界合并独立数字例子。

基础公式、曲线和全部信息卡在开始约两秒内呈现，真实语音cue用于强调而非延后主体。未通过审查的教学成片提供“修复并重新审查”入口，沿同一任务检查点继续，保留旧版本与失败记录，实际输出新文件。

语音输入将`e平方`展开为“残差的平方”、`p_t`为“正确类别概率”、`易例`为“简单样本”，图解保留符号与术语，避免零基础观众只听到含糊的字母。成片出现错读、残句或漏字时，增加相关章节的声音修订号`chapterVoiceRevisions`，强制生成新的真实音频，并保留统一参考；音色整体不一致才重新生成声音参考。抽帧覆盖各章最后一个实际触发词之后的完整卡片状态，不能因为70%时刻尚未出现最后的信息点就报告遗漏。成片语义审查低于80分始终需要复核。

成片进行逐段及混音两遍响度处理，再实测综合响度、分段极差、相邻段跳变、段内变化、峰值和削波。模型听辨真实分段音频的音色一致性，并评审完整音频及最多24张教学关键抽帧。来源是实际联网检索引用与独立脚本审查，不等同于逐条读取论文全文；转写时间码是模型估计，抽帧不等同于逐帧观看。这些限制进入作品记录。

任务的 `workflow` 保存脱敏工具输入、结果、拒绝原因和耗时；页面默认折叠。不会保存模型内部思维链或媒体base64。制作检查点与缓存以用户、任务、原指令和媒体哈希隔离；重试可复用真实通过的工作。`GET /api/artifacts/:id/edit-report` 下载实际方案、工作流和审查。

同一任务恢复时合并已完成的工具记录；中断中的调用标记为失败并说明服务重启，不默认视为成功。历史失败保留在页面与制作记录中，不能用最后一次成功掩盖之前的返修。

Seed 2.1 Pro规划使用262144最大输出token和1024000上下文，Lite使用256000最大输出token；实际请求参数记录于教学任务的 `llm-request-meta.jsonl`，不包含凭证。输出上限和上下文容量是不同参数，不以输出上限替代上下文管理。

验证：`node --import tsx --test tests/*.test.ts`、TypeScript检查、Vite构建，以及在新会话通过页面提交原始一句话并审阅真实产物。端到端验收的成片、播放证据、制作记录和测试日志单独留存，不纳入源代码发布；单元测试通过不代表实际模型、声音和画面均通过。

实际ASR中的`[听不清]`等占位不能用整章高匹配率放行；在渲染前独立复听同一音频，仍无法确认则重录。保留原始识别和占位，不根据脚本猜补缺字。已知同音词仅在本章明确出现对应术语时规范化并保留时间范围；易样本、难样本等名词短语不可把修饰词拆成孤字字幕。

恢复任务时，原始音频的生成键和内容哈希均匹配，且沿用已核验变速后的预计时长距目标不超过2%（至少允许0.5秒）时，保留原变速参数及实际波形，复用原ASR。任一原音频改变、参数越界或时长不符合要求，则重新测量和核验；不能用旧转写替代新音频。变速参数在核验前写入检查点，避免中断后因微小的再次计算使整片ASR失效。
