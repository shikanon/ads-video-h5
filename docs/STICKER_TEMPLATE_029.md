# 动态表情套装与分享视频：第一阶段

来源是「检查 Codex 应用侧连接」中的轻喵第2弹24套透明动态表情，以及「了解网页动画渲染能力」中的《被你哄好的一天》网页动画工程。实现基于已合并的0.2.8代码，与本地0.2.9导航更新一并交付。

## 使用

小程序进入「模板 → 动态表情套装 → 使用模板」。点击任意动作预览透明GIF；选择6个动作的播放顺序、片名和每幕短句。勾选「同步制作表情包分享视频」会交付表情套装和24秒、1080×1440、30fps的MP4，可关闭音乐。取消勾选只保存表情。

任务沿用现有队列、停止、重试、会话进度和任务完成通知。结果同时进入当前会话及「资源 → 成片」；表情包有独立筛选，点击进入动作预览和ZIP下载分享。视频播放器可保存MP4，并下载可编辑网页工程与横竖封面。不会自动发布到抖音或微信表情平台。

## 可复用内容

- `skills/qingmao-stickers/SKILL.md`：原角色、画风、动作、导出与验收规则；清楚标记第一版只复用现有素材。
- `template.json`：模板名称、样片、版本、默认参数、管理后台测试案例。
- `assets/pack.json`：24个动作、每项10个播放帧的停留时间、默认故事顺序及所有资产SHA256。
- `assets/pack/<id>/`：原始GIF/WebP/APNG/静态PNG、小缩略图以及用于视频的透明WebP图集。
- `renderer.js`：共享的确定时间采样渲染器；网页工程和视频逐帧导出使用同一实现。
- 每次结果保存结构化输入、模板/素材指纹、配套视频关联及技术验收记录。标题与短句改变时复用现有表情。

表情交付ZIP含96个表情文件、4份专辑配套文件及一份清单。视频工程包含HTML、配置、渲染器、可选音乐、分镜检查图、横竖封面及验证记录。原动画每项是6张绘制关键帧编排为10个播放帧，并非10张独立绘制原画。

## 运行与部署

新功能需要同时更新后端代码及`skills/qingmao-stickers`资源目录。素材约118MB，放在服务器，不打入小程序主包。服务使用现有Chromium配置（`QINGJIAN_CHROMIUM_PATH`）和FFmpeg，无新增付费模型调用。

公开接口仅提供已确认样片、缩略图、GIF预览；账号交付ZIP、MP4和工程仍按现有所有者鉴权。预览接口限定注册动作ID和固定文件类型，不接受文件系统路径。生成接口验证结构化参数，冻结到任务，并通过请求标识防止重复提交；同一标识携带不同参数会拒绝。

这是本地实现。未部署后端、上传微信、提审或发布。正式小程序目前的远程接口只有部署本次后端后才会列出新模板。

`tests/stickerPacks.test.ts`覆盖素材指纹、参数边界、表单/重试、真实HTTP鉴权、任务队列、ZIP内容及跨账号隔离。设置`QINGJIAN_STICKER_RENDER_TEST=1`会实际生成完整视频与工程，并核对720帧、24秒、音轨和完整解码；测试使用隔离账号和数据目录，断言没有模型请求。

`tooling/verify-sticker-ui.mjs`用于官方组件模拟器的390px/320px布局检查和截图。浏览器组件模拟器不替代微信真机验收。
