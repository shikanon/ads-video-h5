# 创作手册与工作台布局（2026-11-21）

本轮在本地0.2.12迭代，保留原四个Tab顺序及无限画布。工具侧栏新增笔记、资产和MV入口；人物、场景、MV及个人模板在创作手册中切换。

## 视频参考的应用

逐段查看用户提供的33秒视频：编辑区、人物卡片、灵感记录、新增面板、版本卡片、章节大纲。借鉴其“当前项目常驻—中部编辑—关联资料卡片”的信息层次，不将小说示例里的文字或人物当作产品需求。小程序采用单列卡片，避免把桌面多栏和统计图压缩到手机上。

- 顶部：当前项目、未保存/已保存状态、保存修订号。
- 中间：按笔记、人物、场景、MV或模板显示对应编辑区；展示字数与附件数。
- 资料区：可搜索保存的笔记和模板；人物与场景资产可引用、改名、移出分类或删除原素材。
- 常用操作：保存、交给轻喵、查看项目、复制；音频识别按钮仅在已有音视频附件时显示。

## 本轮功能边界

笔记保存标题、正文、附件和标准化手绘笔画，支持更新冲突检查及删除。手绘可撤销并导出为私有PNG素材。语音入口目前接收上传的语音/音频文件，经现有音频理解任务转写，再用于整理；本轮没有新增麦克风直接录音。

人物与场景生成接入已有Agent任务，提示保留外观/画风并说明不可处理参考图的原因。归档资产为显式操作，不将模型文字回复冒充生成图片。

原有MV文字规划入口仍先上传音频并完成实际识别，不编造歌词、BPM或不存在的识别结果。另新增“原素材复刻MV”项目：独立绑定参考片、配乐与最多100项原素材，参考片只用于分析，不能作视觉输出源。短剧仅在手稿中出现标题，未添加制作流程。

作品可提取模板草稿，关联原作品的私有素材及原请求附件。草稿经过用户编辑后可带入工具输入框复用，选择本身不启动计费，也不执行或安装提取出的代码。未自动修改全局系统技能。

笔记的Agent会话保留项目链接；对话结果提供返回创作笔记入口。所有笔记、来源、素材分类和会话关联均验证账号归属，退出账号清理待带入的模板内容。

TypeScript及微信官方WXML/WXSS构建通过。新增功能及原导航/工具回归先后完成45项和21项针对性测试；新增手绘坐标回归通过。一次本地真实HTTP夹具启动超过30秒，单独重跑后通过，未将其记录为功能通过。最终21项回归全部通过。

微信模拟器检查了文字编辑、手绘实际落点（含标准化数值）、MV切换及手机布局。截图：`D:/ads-video-h5-diagnostics/0212-native-visual-check/creative-*.png`。这些是受控演示，未调用生产生成。未部署服务器、未上传微信；新增接口需要前后端配套发布。

## 原素材MV复刻

新增持久化接口 `/api/mv-recreations` 和原生页面 `pages/mv-recreate/index`，按账号隔离参考片、原素材、分镜及产物。流程为抽帧理解、分镜核对、20秒样片、逐节点渲染、合并并一次性合入连续配乐。支持项目改名、删除记录、修改分镜、停止、重试、查看独立节点和从对话返回项目；修改分镜会使旧批准及旧成片关联失效，已有历史作品保留。

实际文件哈希用于分析复用与渲染缓存验证；每个镜头0.2–30秒、30fps，源时间不能越界，净时长必须匹配目标。静态图片以保留整张图片的边距作缓慢推进；连续录屏保持比例，不生成新角色。节点缓存、合并树和最终收据保留以续做。配乐检查实际音轨和时长，不循环、不变速。

技能说明进入实际规划模型，同时公开到轻喵能力目录。模型候选方案与具体字段校验错误保留在项目私有目录。任务通过现有队列、积分用量、停止信号、运行环境指纹及账号校验；生成视频按播放接口实际使用的 exports 类别保存和上传。

原片区间实际重叠时，程序拒绝模型声称“不重叠/未覆盖”；修改分镜时向模型提供已有方案和具体诊断。章节标题位置按排好的镜头计算。渲染前按预计输出检查可用空间并预留512MiB，限制FFmpeg滤镜线程；合并缓存同时校验两个父节点哈希。删除项目记录会清除该项目制作缓存，独立作品继续保留。

新增回归实际渲染250秒测试片，覆盖图片、字幕、连续音乐、完整解码；短片回归覆盖中断后复用节点哈希、失效批准、账号隔离及重复提交。真实HTTP回归从任务队列编排、渲染并通过受保护播放接口读取成片。它们验证技术执行，不能代表《画中归人》视觉或音乐节奏验收通过。参考片使用稀疏抽帧，未实现逐帧动作核验、自动节拍分析或歌词对齐，不宣称逐镜精确复刻。
