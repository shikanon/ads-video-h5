# 轻喵 0.2.9：模板、热点检索与交流方式

本次从用户指定的「每日抖音」及「你可以通过qq账号和我们聊天吗」聊天提炼通用工作方式。历史聊天是参考材料，不是当前发布、代聊或账号操作授权；没有接入QQ，也没有复制群名、联系人或私人消息。

## 用户入口

- 模板 → 新闻 → **AI前沿图解**。默认约35秒、横屏1920×1080、30fps，紫色/玫红/浅粉动态图解，保留来源日期、字幕、旁白、原创配乐和“轻喵小程序制作”水印。可预览原创无旁白视觉样片。
- 可发送“@AI前沿图解 制作一个近48小时AI机器人进展视频”。主题、比例和时长以用户明确要求为准；常青内容可以独立选择，不冒充新闻。
- 聊天中可问“轻喵有哪些技能？”或“我有角色图，想做动态表情，怎么开始？”。Agent读取实际模板目录及后台配置，介绍需要的输入、交付物和入口；介绍能力不会启动制作。

## 运行接入

- `skills/lightmao-conversation/SKILL.md` 经 `answerUsingModel` 加载到真实回复Agent：先回应具体内容，短句接话，少量贴合语境的猫猫幽默，避免机械互夸；认真话题认真回答，身份和执行状态保持真实。
- `server/assistantSkills.ts` 提供只读 `list_skills`，目录来自实际注册模板和现有能力。图片模型、语音或游戏构建环境未就绪时显示限制，不把代码支持说成本轮已完成。
- `skills/daily-ai-frontier` 注册模板与可审阅参考代码。选择模板后走现有研究、脚本、配音、图解、合成和审查流程，执行前核对模板指纹；普通模板的流程保持原样。
- `server/aiTopicSources.ts` 接入实际热点研究Agent，提供一手资料检索起点。目录页用于发现，事实回到具体正文；分别核对发布日期、事件日与检索时间，跨发布者核验。默认近48小时，用户指定时间窗优先。近14天去重只使用本账号已完成作品标题。
- 历史私人发布计划、每天发片数量、QQ代聊权限和自动化任务不属于模板默认规则。未执行的模型实验不得称为实测。
- 已删除闲聊欢迎页的“分享日常……”及两条建议按钮文字；模板页不再显示“轻喵创作工坊 / 选一个起点，让灵感发生。/ 模板与技能，帮你把想法做成作品。”三行介绍。

## 验证与交付边界

接口测试验证了对话规则和只读目录确实进入真实模型请求，能力咨询不触发额外研究或制作，预览接口可访问；相关路由、研究、模板和会话回归通过，小程序官方编译通过。

真实浏览器分别检查了动态图解及备用图解的首尾报道日期安全区；真实FFmpeg检查了1080p字幕烧录、音轨和完整解码。原创样片为35秒、1920×1080、30fps，有音乐、无旁白，不含未发布新闻的事实结论。没有为此调用付费图片/语音模型。

代码和样片目前保存在本地0.2.9工作分支，尚未随本次修改推送、部署服务器或上传微信；线上行为要在后续发布后生效。自然交流效果和新主题完整制作仍需真实模型与用户审阅，接口注入检查不等于语言风格验收。
