# 叙事蒙太奇

这是剪辑方法，不绑定歌曲、歌词、人物或固定素材ID。入口为工具 → 视频 → 音乐MV。用户明确选择自己的音源、素材文件夹、时长和480p/720p/1080p；不能擅自沿用某个旧项目的配乐或参考成片。

先读取真实素材抽帧和所选音频的实际识别结果，再编排起、承、转、合。相近主题按空间、情绪和动作方向建立联系；远景交代环境，中景承接行动，近景表达情绪，避免连续同景别和无意义轮播。视频优先，照片可缓慢推近，镜头一般2–6秒，叙事需要时延长。直切保留动作力度，短叠化连接情绪；保持画幅和主体完整，不重复缩小或重复加黑边。不得虚构BPM、精确卡点或未观察到的动作。

音源完整连续使用目标时长，不变速、不循环、不混原素材声音。歌词只采用实际音频识别草稿；间奏留空，听不清处不根据记忆补写，不因文件名就认定歌名和歌手。草稿与模型估计时间需在项目中可校对。剧情字幕只用用户明确提供的原文，不能用编造的台词充当歌词。两层字幕分开，不能遮挡主体或改变画面比例。

每个镜头保留来源ID、入点、时长和选用理由。净时长精确匹配用户选择，源时间码不越界。不够素材时说明需要补充什么，不用参考成片冒充原素材。按节点渲染并复用核验通过的节点，合成后检查清晰度、时长、音轨和全片解码。真实成片作为产物返回同一画布，提供查看、重命名、删除和分享；失败保留可复用阶段。技术通过不等于用户已验收。

预计积分按当前模型价格与素材量估算，最终按供应商实际用量记账。不得编造每秒固定收费，也不得用分享作为制作前提。
