# 角色表情套装与分享视频

区分两种输入：复用 `assets/pack.json` 的轻喵第2弹，或以用户上传的角色图创建私有表情项目。不能把原角色素材改名后当成新角色生成结果。

## 新角色流程

- 独立提供静态、动态两种模式。角色图、画风、动作配方、素材版本分别保存；参考图只从当前账号明确选择的图片读取。
- 新项目通过“轻喵表情包画风”工具进入。先检查原图可用性，再用24张轻喵表情及两种效果参考生成柔彩肖像Q版、圆萌大眼Q版两张候选；用户必须实际点选一种，服务器绑定候选像素、参考来源和模型指纹后才能生成动作。轻喵不是第三种并列画风；整套锁定所选绘稿。候选与动作样张分阶段报价和确认，不自动续做。旧项目沿用原有已确认画风，不强迫重新付费。
- 原图无法确定单个主角、太小模糊或严重遮挡时停止制图，明确可见原因，并建议换成单个主体、脸部与服装清晰、尽量全身的原图。不一概拒绝截图、动物或半身图；保留无法确认的细节。上游拒绝输入时不盲目重试或绕过，建议换图或核查。
- 使用 `references/generation.md` 的生成配方。先生成贴贴、摸摸头、心动3个样张并停止。用户未确认当前样张指纹前，禁止批量生成。
- 确认绑定角色图、画风、模型、动作配方与3个真实样张。不能用客户端布尔值冒充确认；输入、样张或配方变化后重新确认。批量阶段复用样张，仅补21项。
- 动态生成每项6张独立原画，编排成10个播放帧；不得把6张说成10张独立原画，不用整体平移缩放冒充动作。静态生成单张透明原画，不假造GIF交付。
- 保留参考角色的脸、头发、服装、配件和比例。检查透明度、画幅、主体边界、帧差和网格稳定性。按 [画面验收规则](references/quality.md) 独立观察每张原画，动态逐帧核对完整性、器官数量、角色与画风、动作、道具和裁切；全部通过才提供样张。角色身份和画风仍需用户确认，不将机器质检说成最终验收。
- 默认单个完整主角，“贴贴”用爱心抱枕表现，不能多画一颗没有身体的头。照片中的话筒、手机、舞台和界面不自动继承为配饰。新角色使用单角色动作配方，不直接照搬原轻喵互动构图。
- 无透明背景、空白、重复帧、明显位置跳动或画面验收不通过时保留现场；不静默用原轻喵替代。不合格原画最多自动修正一次，质检与本次修正不额外扣用户积分；仍不合格停止交付。通过的结果重试复用；外部操作结果未知时停止。

## 交付

- 静态：24份主题命名的透明PNG、横幅、封面、图标和介绍。
- 动态：24套GIF、WebP、APNG、静态PNG及专辑配套素材。
- 可选6个动作并按选择顺序编排视频，每幕短句、片名和音乐可设置。24秒，1080×1440，30fps，无口播。
- 表情与视频使用同一素材清单和来源指纹，不重新生成近似角色。私有套装、图集、样张、GIF及工程按所有者隔离，不放进公共样片。
- 网页预览与视频共用确定时间采样，真实检查时长、尺寸、帧数、音轨、完整解码与分镜。交付MP4、横竖封面、可编辑网页工程和制作记录。
- 原角色复用不新增模型生成；新角色制图调用图片模型并保留费用收据，单价未知记为待核对，不声称免费。
- 技术检查不代表最终用户视觉验收；不自动发布至微信表情平台或抖音。
