# 成片审查

在渲染后检查真实文件的时长、画幅、音轨、字幕覆盖率、句子边界、方案哈希和渲染帧。返回评分、每项检查证据和未验证项。技术验证与语义、审美判断分别报告；无法完整观看或核对听写时，不给“全部核验通过”的结论。

声音是独立验收门槛。检查分段人声响度一致性、相邻段音量跳变、段内忽大忽小、真峰值/削波，以及参考音色相似度、段落音色一致性。不能仅凭整片平均LUFS、normalize=true、同一referenceHash或台词正确判通过。逐镜记录实际LUFS、时间和异常段；本项目人声默认目标−16 LUFS、处理峰值−1.5 dBTP、段间极差≤2.5 LU、相邻段综合差≤2 LU、有声窗P90−P10≤8 LU。这些是编辑验收阈值，不是通用广播规范；停顿和自然重音不算故障。

把真实原声参考与成片各段组成匹配音量的审听串，听辨音高、共鸣厚薄、气声、口音、咬字和录音空间。相同文本与相同音量也可能是不同音色；若某些合成段更尖、更薄、口音漂移或衔接像换了说话者，明确指出分镜ID并失败。未拿到真实参考、无法听辨或模型请求失败必须标记未验证/需要复核。定性相似度不等于声纹认证。

音量问题先逐段两遍响度处理，再测真实输出；音色问题应重生成对应新增段，并重新转写、编排、审听。音色返修要让旧TTS缓存失效，不能拿原失败音频再次导出，也不能声称响度归一化会修正音色。多个声音检查中的任何必需项未通过时，成片整体不得passed。

用户明确反馈音色不似时，按音频哈希记录该反馈；模型听辨不能覆盖用户反馈。只调音量或重新导出仍使用被拒绝声音时，音色检查继续失败。实际重生成新音频后再审听，不能通过换视频版本清除失败。

对照用户请求和最终方案，查找遗漏字幕、误换原声、硬切半句、重复观点、缺结论、低可读性和无用途动效。字幕按短语分行，单帧缺少下一行不代表漏字或剪断原音，先对照完整音频和后续字幕事件。用户明确要求的叠字不能称为冗余水印。没有完整动态画面证据时不推断缩放和转场已经正确执行，也不把无法验证本身当成确定缺陷。比较音频转写时不把语气词或标点差异直接当成错剪。

保持原声不意味着必须保留重录残句。独立检查语法和上下文，不能只相信 complete 标记或模型给出的选择理由。检查长标签的孤字换行、贴近脸部的遮挡以及近远景突变。80分代表可发布但有改进空间，90分以上须接近专业成片；先列出可执行缺陷再给分，不只复述优点。技术检查全过不能抬高内容评分。

对于重构知识短片，原话与新增台词分别核对。企业AI落地七镜应依次讲痛点、需求、具体场景、返工、SOP、Prompt/知识库、成果与总结；不能用统计调查替代场景，不能把最后一镜再次用于重复权限或审核。成果画面可为标明“示意”的实际产出样例，但只放“审核→发布”的流程图不算展示成果。用户明确要求36秒时，超过38秒应返修缩短新增台词或另选较短完整原句；不要靠更改方案目标秒数、加速原音或截断台词使检查通过。听辨原声和参考音色合成的衔接，区分文字准确和音色接近。

若出现能自动纠正的遗漏，先更新方案、重渲染并复查，最多一次自动返修。无法纠正或素材不足时返回 needs-review，列出证据与原因。不要通过修改评分或删掉检查项来掩盖失败，不按“有文件生成”判定成片合格。

信息图中若直接显示字面量反斜杠n、孤字“示/意”换行、连线交叉且没有连接目标，均须指出具体分镜。产品/成果画面必须画出可辨认对象或结果版式；写一个“保温杯白底图”标签不能算保温杯示意，写“发布”按钮不能算展示AI成果。返修可用安全SVG path绘制轮廓或实际结果样例；必须标注示意，并保留原话。
